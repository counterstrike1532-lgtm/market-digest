## Принципы, которые не пересматривать

- **Квота Gemini: 20 запросов в сутки на модель, лимит на проект.** Вся архитектура
  вокруг этого: отбор одним запросом, черновики одним, верификация максимум одним.
- **Автоисправление цифр запрещено.** Та же модель не найдёт свою ошибку, а тихая
  правка отключает последнюю линию обороны — глаза владельца. Верификатор помечает,
  не редактирует.
- **Alarm fatigue — реальный отказ системы.** Верификатор, который всегда показывает
  ⚠️, хуже отсутствующего: через неделю его перестают читать, и он пропустит настоящую
  ошибку. Это было основанием для T10c.
- **На картинку попадают только числа со статусом FOUND.** Картинка расходится по
  ленте без контекста, планка для неё выше, чем для текста.
- **Картинки — заготовка мысли, не публикуемый ассет.** Финальный график владелец
  делает сам, когда решил, что постит. Не строить конструктор.
- **RANK_PROMPT и калибровка DRAFT_PROMPT священны.** TONE CEILING (студент,
  не профессор), позиция объясняющая, первое лицо только про реально сделанное,
  максимум один черновик из трёх заканчивается вопросом, все три SKIP — валидный исход.
- **`style/my_posts.md` наполнять только своими постами.** Чужие (Goldman/JPM) ломают
  TONE CEILING.

## T11 — кандидаты, решать после понедельника

1. **Story [N] fallback для SOURCE черновика** (~30-45 мин). `build_domain_urls()`
   включает домен только при ровно одном URL на домен, а у bankier.pl обычно 3-4
   сюжета — значит голый домен в SOURCE останется текстом без ссылки. Пока не кусалось:
   модель писала полные URL. Не гарантировано.
2. **Единицы измерения в верификаторе или строка в промпте.** `_to_search_variants`
   переводит формат числа на польский, но не слово: `93,000 hectares` → `93 tys.
   hectares`, никогда `93 tys. ha`; `4.1 million tons` никогда не станет `4,1 mln ton`.
   Это дало 0/4 FOUND у DRAFT 3. **Дешёвая альтернатива**: DRAFT_PROMPT вообще
   не просит цитировать форму источника в скобках — цитаты вида `("406 tys.")` модель
   ставит по своей инициативе. Одна строка в промпте может оказаться дешевле перевода
   единиц в коде. Решать по факту понедельника, не заранее.
3. **Предохранитель от живых прогонов.** `brain._call` отказывается работать без
   переменной окружения `NEWSBOT_ALLOW_LIVE=1`, которую ставит только запуск владельца.
   Делает нарушение технически невозможным, а не запрещённым.
4. **FRED_API_KEY** — 15 минут владельца на fred.stlouisfed.org, ключ в GitHub Secrets
   и secrets.ps1. Код готов, блок US-данных молча пропускается.
5. **Лаг HICP Eurostat** — при `lastTimePeriod: 1` отдаёт 2025-12. Декодер починен,
   причина на стороне запроса не разобрана. С T10f протухшее просто не печатается,
   так что не блокер. Альтернатива: GUS CPI flash для Польши — неделя лага вместо
   восьми месяцев, и NBP смотрит именно на него.
6. **Базы на графике рынков**: WIG20 TR (с дивидендами) против ценового S&P 500,
   польская линия систематически выглядит лучше. Примечание в подвале есть.
   Вариант — `^SP500TR` с фолбэком на ценовой, тогда сравнение TR vs TR и примечание
   не нужно.
7. **Динамическая приоритизация источников** — идея принята, ждёт месяц статистики
   в `metrics.json`.
