## Состояние: РАБОТАЕТ end-to-end

Каждое буднее утро ~7:00 Варшавы сводка приходит в ТГ сама. Пайплайн:
21 RSS-источник (~280 записей) → дедуп по ссылке и заголовку → эвристический предотбор
до 100 БЕЗ LLM → цифры (NBP FX, stooq WIG20/SPX/NDQ, Eurostat HICP; FRED опционален,
ключа нет) → отбор Gemini ОДНИМ запросом → догрузка текста статей (обычно 4-6 из 6;
пейволлы Axios/MarketWatch не лечатся) → черновики ОДНИМ запросом → ТГ кусками по 3900,
parse_mode HTML → state/seen.json коммитится ботом обратно (защита от повторов 21 день).

Расход: 2 запроса Gemini на прогон. Локальный запуск: digest.cmd (двойной клик,
сам делает git pull) или .\run.ps1 verify|models|dry|send|score.

## ЖЁСТКИЕ ОГРАНИЧЕНИЯ (нарушение = день отладки заново)

1. Квота Gemini free tier: 20 запросов/СУТКИ на модель (GenerateRequestsPerDayPerModel).
   Не минутный лимит! Вся архитектура построена вокруг этого: никаких батчей,
   отбор одним запросом. Сброс ~09:00-10:00 UTC.
2. Модели: gemini-3.5-flash,gemini-3.6-flash,gemini-3.1-flash-lite (порядок = приоритет).
   3.1-lite заметно слабее в аналитической глубине углов — не ставить первой.
   gemini-2.5 у владельца НЕ работает. Проверка доступных: .\run.ps1 models.
3. Моделям gemini-3* НЕЛЬЗЯ слать thinkingConfig.thinkingBudget:0 — это 400.
   В _call() есть проверка startswith("gemini-3").
4. 400 от Gemini детерминирована — не ретраить тем же телом; код снимает параметры
   по одному и логирует тело ответа. 429 бывает двух типов: PerDay (сразу следующая
   модель, без пауз, помнить в _day_exhausted) и остальное (backoff).
5. .ps1 и .cmd файлы — ТОЛЬКО ASCII. PowerShell 5.1 без BOM читает их как cp1251,
   кириллица ломает парсер. Сообщения в них по-английски.
6. Каждое чтение/запись файла в Python — с encoding="utf-8". Системная кодировка
   владельца cp1251, без явного аргумента падает на кириллице.
7. Никаких новых зависимостей без явного разрешения. Сейчас: requests, feedparser,
   PyYAML. Для T8a разрешён matplotlib (только он, Agg-бэкенд).
8. Reddit отдаёт 403 всегда — это норма, не чинить. NBP новостного RSS НЕ имеет —
   закрыт через Google News RSS (обычный RSS с q=, менять темы в config/sources.yaml
   без кода). Eurostat RSS пустой — не важно, данные идут через API.
9. Все внешние вызовы в try/except: один упавший источник не валит прогон.
10. У владельца Windows 11, PowerShell 5.1, Python 3.14 локально / 3.12 в Actions.

## КАЛИБРОВКА ПРОМПТОВ (src/brain.py) — не откатывать

RANK_PROMPT: жёсткая отбраковка шлака, требование разброса оценок (иначе всё 8/10),
angle до 35 слов и обязан называть конкретный механизм/статью баланса
("процентный доход на остатках клиентов", не "высокий операционный леверидж"),
запрет выдумывать цифры не из сниппета.

DRAFT_PROMPT: 110-170 слов; позиция ОБЪЯСНЯЮЩАЯ, не вопросительная ("I might be wrong",
"What am I missing" запрещены — владелец прямо возражал); числа ТОЛЬКО из догруженного
текста статьи или блока FRESH DATA, с указанием источника в поле FIGURES; числа в
английском формате (2.6%, не 2,6%); первое лицо ТОЛЬКО про реально сделанное
("I pulled figures from Statistics Poland" — да; "I tracked this fund" — НЕТ, модель
однажды выдумала участие владельца, это опаснее выдуманной цифры); три разные структуры
A/B/C; запрет banned-слов (leverage, synergy, delve...); хэштегов 0-1, не generic;
ссылок в теле нет; запрет сравнивать величины с разными базами (годовой контракт vs
многолетний план) — если базы разные, "Nx" не считать; пробел после точки.

SCORE_PROMPT + src/score_draft.py: скорер готового поста, 10 локальных проверок
бесплатно + --deep через Gemini. Судит, НЕ переписывает.

- Микс контента: дайджест-посты из бота ~1/нед + посты-события (сертификаты, конкурсы)
  + в нужный момент пост "ищу практику". Комментарии под постами аналитиков важнее
  собственных постов (нетворк 460 холодный, лайки не метрика).
- Twitter (T3) отложен сознательно: материала избыток, риск/поддержка не окупаются.
- style/my_posts.md ПУСТОЙ — наполнять реальными постами владельца по мере публикаций.

- LinkedIn режет: engagement-bait ("What do you think"), внешние ссылки в теле,

T8a: src/charts.py + chartstyle.py. Современные карточки (НЕ Excel): темы dark

T8b: черновики → 2 дайджест-варианта (120-170 и 80-110 слов, "три вещи недели") +
  1 одиночный. TONE CEILING: слово, которое студент не сказал бы вслух, — ошибка.
  У дайджестов FIGURES может не быть — не требовать.
T8c: полякоцентричный скоринг ("would someone in Polish finance raise an eyebrow");
  VERDICT: POST|MAYBE|SKIP + WHY + CHECK_FIRST у каждого черновика, фильтр по списку
  компетенций владельца. Все три SKIP — честный исход.
T8d: закрывающий вопрос максимум в 1 из 3 черновиков, только приглашение экспертизы
  с конкретикой; src/verify.py — ВЕРИФИКАТОР цифр, НЕ редактор (автоисправление
  запрещено принципиально: та же модель не найдёт свою ошибку, а молчаливая правка
  отключает глаза владельца). Уровень a: посимвольное вхождение нормализованного числа
  в текст источника, без LLM. Уровень b: +1 запрос, MATCH/MISMATCH по контексту
  (год, "на" vs "до"). Проблемная цифра → VERDICT принудительно MAYBE. Итог ✅/⚠️/❌
  в сводке. Бюджет: 3 запроса на прогон из 20.

Порядок: T8a → T8b → T8c → T8d, приёмка после каждой, коммит после приёмки,
/clear между частями. Чек-листы приёмки — в самом ТЗ.

## Известные мелочи (не баги)

- Расписание Actions запаздывает на 5-20 мин, иногда пропускает прогон — платформа.
- enrich с IP GitHub догружает меньше статей, чем локально — ожидаемо.

- Плановые воркфлоу отключаются после 60 дней без коммитов; ежедневный коммит
  seen.json это самоподдерживает, но после долгой паузы включать вручную.
- Крон 0 5 UTC = 07:00 Варшавы летом, 06:00 зимой.
- FRED_API_KEY не заведён — блок US-данных молча пропускается, не критично.
