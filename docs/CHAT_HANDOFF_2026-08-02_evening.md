## Новый режим работы: ежедневное ревью

Прогоны ради прогонов больше не делаем — крон и так шлёт дайджест каждое утро,
чтение того, что пришло, не стоит ни одного запроса.

`docs/DAILY_REVIEW_PROMPT.md` — готовый блок, владелец копирует его в новый чат
вместе с сообщениями из Телеграма. Главное правило внутри: **правка
DRAFT_PROMPT только если тот же тик встречался раньше**; одноразовая странность
записывается и ждёт повтора. Иначе калибровка развалится за неделю.

## ГРАБЛИ

1. **Текст из Телеграма — по сообщениям, с маркерами** `=== СООБЩЕНИЕ 1 ===`.
   Склеенный копипаст один раз уже стоил полдня поиска несуществующего бага.
2. **Ссылки Телеграм линкует сам.** `www.bankier.pl` станет кликабельным
   независимо от нашей разметки. Не диагностировать это как баг разметки —
   поэтому T12a и убирает печать SOURCE вовсе, а не «печатает текстом».
3. **Гипотезы проверять по коду.** За два дня две неверных: «дедуп смешивает
   URL» (T10b) и «опечатка в SOURCE самолечится через T11c». Вторую Claude Code
   сам же и опроверг трассировкой — это правильное поведение, так и надо.
4. **Перед Run workflow — `git push` и сверка** `git log --oneline -3` против
   `git log --oneline -3 origin/master`. Сегодня поймалось: шесть коммитов T11
   лежали только локально. Ветка `master`, не `main`.
5. **`git log origin/master` показывает локальную копию ссылки.** Она устаревает,
   пока не сделан `git fetch`. Отсюда «rejected non-fast-forward» при внешне
   правильном логе.
6. **Локальный `send` коммитит `state/` в репо.** Сегодня это пометило вечерние
   сюжеты виденными для утреннего прогона, пришлось откатывать руками. Правило:
   состояние публикует только Actions. Кода для этого пока нет — кандидат в T13.
7. **Диффы промптов владелец смотрит глазами до боевого прогона.** Шапка ханка:
   смещение номеров строк выдаёт, что выше есть ещё изменённый кусок.
8. **Артефакт `digest-log-*` не содержит текста сообщений**, только сводные
   INFO-строки. Текст владелец копирует из Телеграма руками.

## Принципы, которые не пересматривать

- **Квота Gemini: 20 запросов в сутки на модель, лимит на проект.** Отбор одним
  запросом, черновики одним, верификация максимум одним.
- **Автоисправление цифр запрещено.** Верификатор помечает, не редактирует.
- **Alarm fatigue — реальный отказ системы.** Верификатор, который всегда
  показывает ⚠️, хуже отсутствующего.
- **На картинку попадают только числа со статусом FOUND.** Ноль картинок за
  прогон — валидный исход. Картинка появляется по событию, а не по расписанию.
- **Картинки — заготовка мысли, не публикуемый ассет.**
- **RANK_PROMPT и калибровка DRAFT_PROMPT священны.** TONE CEILING (студент, не
  профессор), позиция объясняющая, первое лицо только про реально сделанное,
  максимум один черновик заканчивается вопросом, все SKIP — валидный исход.
- **`style/my_posts.md` наполнять только своими постами.** Чужие ломают
  TONE CEILING.
- **Никаких живых прогонов Claude Code без явного разрешения на конкретный
  вызов.** Теперь ещё и технически (T11a).
