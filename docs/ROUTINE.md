# Как этим пользоваться

## Каждое утро, 2 минуты

```powershell
cd C:\Users\X1\Desktop\Analizer\newsbot
.\run.ps1 send
```

Сводка придёт в Телегу: цифры, 8 сюжетов с углами, 3 черновика. Читаешь, ничего не делаешь.

Главная польза здесь — не посты, а то, что на собеседовании в IB на вопрос «что сейчас
происходит на рынках» ты отвечаешь без подготовки. Посты — побочный продукт.

Пока не сделан T6, запуск ручной. После переноса на GitHub Actions приходить будет само,
компьютер включённым не нужен.

## Раз в неделю, когда есть что сказать

Не по расписанию. Один хороший пост в неделю лучше пяти проходных, и сомневаешься —
не публикуй, пропущенная неделя не стоит ничего.

**1. Выбери сюжет из накопившихся за неделю.** Ищи не «важное», а то, где у тебя есть
своё: посчитал, заметил расхождение, знаешь польский контекст.

**2. Сверь каждую цифру с первоисточником.** Обязательно, без исключений. Числа в углах
пришли из машинного чтения статьи, и вся конструкция поста на них держится. Если сюжет
помечен `! текст статьи не догружен` — цифр там нет вообще, только качественный аргумент.

**3. Проверь базы сравнения.** Год против квартала, годовой контракт против многолетнего
плана, поток против запаса, номинал против реального. Арифметика может сходиться, а вывод
быть мусором. Ловят на этом мгновенно.

**4. Напиши сам или перепиши черновик.** Черновик — заготовка, не готовый текст.

**5. Прогони через скорер.**

```powershell
.\run.ps1 score draft.txt
```

10 локальных проверок, квоту не тратит. Если всё PASS и хочешь мнение по смыслу —
`--deep`, но это 1-3 запроса Gemini.

**6. График, если он что-то добавляет.** Заливай нативной картинкой в LinkedIn.
Внешние ссылки в теле поста режут охват.

**7. Комментарии важнее постов.** 5 осмысленных комментариев под постами аналитиков
целевых банков дают больше, чем 5 постов в пустоту: комментарий ставит тебя прямо перед
тем человеком, до которого ты хочешь дотянуться.

## Квота Gemini

**20 запросов в сутки на модель.** Прогон стоит 2 (отбор + черновики), то есть
10 прогонов в день. Сброс около 09:00-10:00 UTC.

Не гоняй `dry` без причины. Порядок моделей в `secrets.ps1`:
`gemini-3.5-flash,gemini-3.6-flash,gemini-3.1-flash-lite` — три модели дают 60 запросов
в сутки суммарно. Lite слабее держит аналитическую глубину, для черновиков лучше 3.5.

## Если сломалось

| Симптом | Команда / причина |
|---|---|
| Мало сюжетов, странные источники | `.\run.ps1 verify` — фиды умирают, это нормально |
| `Gemini недоступен` | `.\run.ps1 models` — имена моделей меняются |
| 429 сразу на всех моделях | суточная квота, ждать сброса |
| `reddit -> HTTP 403` | норма, не баг |
| `пусто: rss_estat_news` | норма, данные Eurostat идут через API |
| `UnicodeDecodeError` | забыт `encoding="utf-8"` в новом коде |
| PowerShell не парсит `.ps1` | в файл попала кириллица, только ASCII |

Подробности в `CLAUDE.md`, раздел «ГРАБЛИ».

## Что осталось несделанным

- **`style/my_posts.md` пустой.** Заполняй своими реальными постами по мере выхода —
  оттуда генератор берёт манеру. Пока пусто, черновики технически правильные, но безликие.
- **T6, GitHub Actions.** Тогда дайджест приходит сам. Репо делать **публичным**:
  у приватных квота минут занята другим ботом.
- **T7, локальный HTML-дашборд.** По желанию.
- **T3, Twitter.** Отложен сознательно: материала уже избыток (270 записей в сутки при
  8 отобранных), а X требует постоянной поддержки и рискует аккаунтом. Возвращаться,
  только если почувствуешь дефицит тем.

## Что не делать

- Не постить по расписанию ради регулярности
- Не публиковать цифру, которую не сверил с первоисточником
- Не писать про то, к чему не имеешь отношения (оборонные заказы Пентагона от студента
  из Варшавы читаются натянуто)
- Не накручивать вовлечённость через поды — ловится и бьёт по аккаунту
- Не гнаться за лайками: пост с 3 лайками, где виден твой расчёт, стоит больше 200 лайков
  на мотивационном
