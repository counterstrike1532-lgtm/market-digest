# Переход на Claude Code

## Перед первым запуском: git

Обязательно. Без него ты не увидишь, что именно Claude Code меняет, и не откатишь.

```powershell
cd C:\Users\X1\Desktop\Analizer\newsbot
git init
git add .
git commit -m "рабочее состояние: дайджест собирается, черновики генерируются"
```

Проверь, что `secrets.ps1` НЕ попал в коммит:

```powershell
git ls-files | Select-String "secrets"
```

Должно быть пусто. Если файл там — `git rm --cached secrets.ps1`, проверь `.gitignore`.

## Дальше по ходу

- `/clear` между задачами T2 → T3 → T4, иначе контекст забьётся и качество просядет
- после каждой принятой задачи делай коммит, чтобы было куда откатываться
- лезет в лишние файлы → «работай только в рамках текущей задачи»
- предлагает платный API или новую библиотеку → «читай ограничения в CLAUDE.md»
- перед T3 скажи: «сначала объясни архитектуру локального коллектора X и почему он не
  в Actions — хочу убедиться, что ты понял»
- начал молча переписывать промпты целиком → «правь адресно и объясняй каждую правку»
