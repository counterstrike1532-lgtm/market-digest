## Установка (20 минут, один раз)

### 1. Репозиторий — ПУБЛИЧНЫЙ

Это важно: у публичных репо Actions на стандартных раннерах бесплатны без лимита минут.
Приватный съедал бы твою квоту (3000 мин/мес на Pro), которая уже занята ботом по КБЖУ.

```bash
git init && git add . && git commit -m "init"
gh repo create news-digest --public --source=. --push
```

Секреты в публичном репо не палятся — они лежат в GitHub Secrets в зашифрованном виде
и в коде их нет. Проверь только, что ты не закоммитил `.env` (он в `.gitignore`).

### 2. Ключи

| Что | Где взять | Обязателен |
|---|---|---|
| `GEMINI_API_KEY` | aistudio.google.com → Get API key | да |
| `TELEGRAM_BOT_TOKEN` | @BotFather → `/newbot` | да |
| `TELEGRAM_CHAT_ID` | напиши боту, открой `api.telegram.org/bot<TOKEN>/getUpdates` | да |
| `FRED_API_KEY` | fred.stlouisfed.org/docs/api/api_key.html | нет |

Settings → Secrets and variables → Actions → New repository secret.

Отдельно в разделе **Variables** (не Secrets) добавь `GEMINI_MODEL`. Проверь актуальное имя
модели в AI Studio — они меняются; в коде дефолт `gemini-2.5-flash`.

### 3. Свой голос — самый важный шаг

Открой `style/my_posts.md` и вставь 3–5 своих постов полным текстом.

Без этого файла посты выходят технически правильные, но безликие. Правила голоса в промпте
только запрещают шлак; **твою** манеру Gemini берёт отсюда. Если постов ещё нет — напиши
2–3 черновика от руки, как сам бы написал. Этого достаточно.

### 4. Прополка источников

```bash
pip install -r requirements.txt
python -m src.verify_feeds
```

Часть RSS-адресов в `config/sources.yaml` наверняка уже переехала или умерла — скрипт
покажет какие, удали их из конфига.

### 5. Тестовый прогон без отправки

```bash
export GEMINI_API_KEY=...
python -m src.main --dry --hours 48
```

Смотри на СЮЖЕТЫ. Если там мусор — крути `RANK_PROMPT` в `src/brain.py`, добавляй
в список отбраковки то, что тебя бесит. Это единственная настройка, которая реально
влияет на качество.

### 6. Включай

Actions → `news digest` → Run workflow. Крон стоит на **05:00 UTC, Пн–Пт** = 07:00
по Варшаве летом. Зимой сдвинется на 06:00 — если мешает, поменяй на `0 6 * * 1-5`.

## Как это устроено

```
collect.py   RSS + Hacker News + Reddit → дедуп по нормализованной ссылке
numbers.py   NBP (курсы) + stooq (WIG20, S&P, Nasdaq) + Eurostat (HICP) + FRED
brain.py     этап 1: жёсткий отбор (0-10, всё ниже 6 в утиль)
             этап 2: черновики по твоему стилю
deliver.py   в Телегу, кусками по 3900 символов
state/       seen.json коммитится обратно в репо → повторов не будет 3 недели
```

## Про Twitter и LinkedIn

Их в сборе нет, сознательно:

- **X** — бесплатного API больше нет, платный от ~$200/мес. Скрейпинг хрупкий и рискует
  аккаунтом. Те же темы всплывают на HN и Reddit с задержкой в пару часов — этого хватает.
- **LinkedIn** — скрейпинг реально банят. У тебя Premium и выстроенный нетворк, терять его
  из-за скрипта незачем. Альтернатива без риска: Google Alerts на `site:linkedin.com/posts`
  по 3–4 темам, письма приходят сами.

## Что подкрутить со временем

- Мало польских сюжетов → поднять `weight` польским фидам до 1.4
- Слишком много ИИ-хайпа → убрать `techcrunch` и `theverge`, оставить `ai_primary`
- Черновики похожи друг на друга → добавить постов в `style/my_posts.md`
- Reddit падает с HTTP 403 → это нормально, он режет IP дата-центров, остальное работает
- Ловишь 429 от Gemini → увеличь `time.sleep(4)` в `brain.rank`
